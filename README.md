# Outer Mind · Mini App

Інтерфейс Telegram Mini App для особистого хабу Outer Mind (задачі, фінанси, огляд).
Сайт публікується через GitHub Pages: https://dramorr.github.io/outer-mind-app/

Зараз це каркас: вкладки, тема Telegram, без даних.

## Правила (репозиторій публічний)

- **Жодних секретів:** токенів бота, ключів Monobank, chat id, особистих даних, файлів БД.
  Усе це живе лише в приватному бекенді бота.
- Сторінка — статика (HTML/CSS/JS, без збирання). Дані вона отримуватиме від API бота.
- API бота довіряє запиту лише після перевірки підпису `Telegram.WebApp.initData`
  на сервері. `initDataUnsafe` на клієнті — тільки для відображення.

## Локально

Відкрий `index.html` у браузері або запусти `python -m http.server` у цій папці.
Поза Telegram сторінка показує каркас і підказку відкрити її з бота.
