# Outer Mind · Mini App

Інтерфейс Telegram Mini App для особистого хабу Outer Mind (задачі, кошик, фінанси, ачівки, огляд).
Сайт публікується через GitHub Pages: https://dramorr.github.io/outer-mind-app/

Зараз працює вкладка «Задачі»: список (термінові / всі / за списком), додавання, виконання з поверненням,
налаштування задачі (назва, пріоритет, список, дедлайн, повторення, коментар), видалення.
Вкладка «Кошик»: список покупок, кілька продуктів за раз, відмітка «куплено» з поверненням, очищення купленого.
Вкладка «Фінанси»: бюджет на сьогодні, підтвердження операцій, готівка, місяць з лімітами, операції по днях і по магазинах.
Вкладка «Ачівки»: рівень і XP, ачівки з прогресом, останні нарахування. «Огляд»: дайджести, підсумки й попередження (ті самі, що бот надсилає в особистий чат).

## Іконки

Усі іконки — піксельні, у стилі значків ачівок: `icons.js` (малюнки 16×16 `ICONS`, мапи «що де» і `icon()`),
символи й палітра — `badges.js`. Емодзі в інтерфейсі не вживаємо; у розмітці іконка — атрибут `data-icon="ім'я"`.

## Як сторінка знаходить бота

Бот працює на ноуті й відкриває до свого API тунель (ngrok з постійним доменом або Cloudflare),
тож бот передає хост API параметром (base64url):
кнопка «Хаб» у чаті з ботом і кнопка «📱 Відкрити Хаб» під його сповіщеннями відкривають
`…/outer-mind-app/?api=<хост>`. Відкрита без параметра, сторінка просить скористатися цими кнопками.

## Правила (репозиторій публічний)

- **Жодних секретів:** токенів бота, ключів Monobank, chat id, особистих даних, файлів БД.
  Усе це живе лише в приватному бекенді бота.
- Сторінка — статика (HTML/CSS/JS, без збирання).
- Кожен запит несе `Authorization: tma <initData>`; бот перевіряє підпис Telegram і що це власник.
  `initDataUnsafe` на клієнті — тільки для відображення.

## Локально

`python -m http.server` у цій папці й `http://localhost:8000/?api=http://127.0.0.1:8787`.
Поза Telegram підпису немає, тож API відповість 401: для перевірки верстки підміни `fetch`.
