# Outer Mind · Mini App

Інтерфейс Telegram Mini App для особистого хабу Outer Mind (задачі, фінанси, огляд).
Сайт публікується через GitHub Pages: https://dramorr.github.io/outer-mind-app/

Зараз працює вкладка «Задачі»: список (термінові / всі / за списком), додавання, виконання з поверненням,
налаштування задачі (назва, пріоритет, список, дедлайн, повторення, коментар), видалення.
Фінанси й огляд — поки заглушки.

## Як сторінка знаходить бота

Бот працює на ноуті й відкриває до свого API тунель Cloudflare (`https://<слова>.trycloudflare.com`),
адреса якого змінюється після кожного запуску. Тому бот передає піддомен параметром:
кнопка «Хаб» у чаті з ботом відкриває `…/outer-mind-app/?api=<піддомен>`, а `/app` у групі —
`t.me/<бот>?startapp=<піддомен>`. Відкрита без параметра, сторінка просить скористатися цими кнопками.

## Правила (репозиторій публічний)

- **Жодних секретів:** токенів бота, ключів Monobank, chat id, особистих даних, файлів БД.
  Усе це живе лише в приватному бекенді бота.
- Сторінка — статика (HTML/CSS/JS, без збирання).
- Кожен запит несе `Authorization: tma <initData>`; бот перевіряє підпис Telegram і що це власник.
  `initDataUnsafe` на клієнті — тільки для відображення.

## Локально

`python -m http.server` у цій папці й `http://localhost:8000/?api=http://127.0.0.1:8787`.
Поза Telegram підпису немає, тож API відповість 401: для перевірки верстки підміни `fetch`.
